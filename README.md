## ⚡ 系统核心功能矩阵

### 1. 自媒体矩阵流水线与热点雷达
* **账号 1：圣多纳释放法实践与心灵疗愈**（4 步释放法预设、核心引导词、学员案例金句拆解）
* **账号 2 & 账号 3：小红书双账号高赞热点搬运雷达**
  * 每日自动筛选 **最高赞（10w+ / 5w+）、最高讨论度（千评级）** 的爆款笔记选题与文案框架；
  * 提供一键「换一批」及多维度排序。
* **账号 4：AI 前沿科技全网矩阵热点雷达**
  * 不仅涵盖官方一手发布（Anthropic、OpenAI、DeepSeek、Google DeepMind），更囊括**知名 AI 科技博主（如宝玉、数字生命卡兹、归藏、Andrej Karpathy 等）高赞解析与实战技巧**；
  * 附带「一键提炼爆款视频脚本」及小红书图文文案拆解功能。

### 2. 英语口语训练与 1000 词深度情境语篇工坊
* **1000 词长篇深度情境语料**：涵盖硅谷大厂 AI 团队敏捷站会、国际商务价格谈判、跨文化学术研讨等深度沉浸语篇；
* **滑动滚轮长卷支持**：本批次语篇长卷专属滚轮导航，流畅查看任意篇章；
* **四步循环口语训练法**：
  1. 泛读沉浸感悟 → 2. 逐句断句精读与意群节奏划分 → 3. 影子跟读（Shadowing）与口语复述 → 4. 自主造句迁移应用；
* **段落点词查词与高亮标注**：鼠标划词或点击任意生词，即时弹出释义浮窗，一键收藏至「我的专属生词库」；
* **四大多元自主导入工坊**：
  * 🌐 粘贴文章网页链接抓取
  * 📄 本地文档上传（PDF / TXT）
  * 🖼️ 灵感图片 OCR 识别提取
  * 🎥 影音素材双语字幕转录

### 3. 专八（TEM-8）系统化备考全能模块
* **听力理解（Listening）**：Mini-lecture 记笔记填空策略 + Interview 访谈核心考点透析；
* **阅读理解（Reading）**：精选外刊社论与文学评论长文，定位长难句攻坚；
* **改错攻坚（Proofreading）**：语法陷阱、倒装、虚拟、代词指代一致性精准纠错；
* **口语与即兴演讲（Oral Presentation）**：即兴表达 3 分钟框架、观点论述模版；
* **写作规范（Writing）**：专八材料议论文黄金五段式结构与高分连接词库。

### 4. 每日效率清单、时间轴与开发者工具
* 番茄钟（Focus Timer）、白噪音助眠/专注背景音；
* JSON 格式化、Base64 编解码、哈希校验、颜色调色盘等全套生产力工具。

## 📱 多端使用与桌面/手机“小程序化”指引

工作台已完整支持 **PWA (Progressive Web App)** 工业级规范与离线缓存，**不限制任何浏览器**，随时可变为独立无边框应用：

### 💻 1. 电脑桌面端（Windows / Mac / Linux）
* **Google Chrome 浏览器**：
  1. 打开工作台网址；
  2. 点击地址栏右侧出现的 **「安装应用」** 图标（或右上角三点 → `保存并分享` → `将网页作为应用安装`）；
  3. 确认安装后，电脑桌面将出现 **KansoDesk 专属图标**；
  4. 启动后**无浏览器地址栏、无多余标签页，全屏沉浸犹如原生桌面软件**。
* **Microsoft Edge 浏览器**：
  1. 点击右上角三点 → `应用 (Apps)` → `将此站点作为应用安装`。

### 📱 2. 苹果 iPhone / iPad (iOS Safari)
* 手机打开自带 **Safari 浏览器** 访问网址；
* 点击底部工具栏正中间的 **「分享」按钮（向上箭头的方框）**；
* 下滑菜单，点击 **「添加到主屏幕」 (Add to Home Screen)**；
* 点击右上角「添加」，手机主屏幕立即生成高清 App 启动图标；
* 点击图标启动，**全屏运行、底部无 Safari 栏，体验与 App Store 原生应用完全一致**。

### 🤖 3. 安卓手机 (Android)
* 若通过微信打开，点击右上角三点 → **「在浏览器中打开」**；
* 在手机浏览器菜单中选择 **「添加到主屏幕」** 或 **「安装应用」**。

## 🛡️ 如何让工作台长期永久使用（永不失效/永不丢失方案）

为了彻底避免“平台停机”、“临时网址失效”或“数据清空”，建议采取以下**永久在线部署与双重安全机制**：

### 方案 A：一键托管到 Vercel（全球免费、永久在线、0 成本，推荐 ⭐⭐⭐⭐⭐）
1. 将当前代码推送到您的 GitHub 个人仓库（见后文步骤）；
2. 打开 [Vercel 官网](https://vercel.com/)，使用您的 GitHub 账号免费登录；
3. 点击 **「Add New...」→「Project」**，选中您刚推送的 `kansodesk` 仓库；
4. 构建配置全部保持默认（Vite 预设自动识别）：
   * Build Command: `npm run build`
   * Output Directory: `dist`
5. 点击 **「Deploy」**，约 30 秒后即可获得一个**全球 CDN 加速的永久专属网址**（例如 `https://your-kansodesk.vercel.app`）；
6. **永久保证**：即使本开发沙盒关闭，您的专属网址也会 24 小时 365 天永久稳定运行，数据完全由您个人掌控。您还可以随时免费绑定自己的独立域名！

### 方案 B：本地离线永久运行
1. 下载代码至本地电脑；
2. 运行终端执行：
   ```bash
   npm install
   npm run build
   npx serve dist
   ```
3. 即使完全断开互联网连接，工作台也支持本地 100% 离线使用。

### 方案 C：数据本地导出备份保障
* 工作台所有修改均实时加密保存在本地浏览器存储；
* 点击右上角齿轮⚙️「设置」→ **「导出完整数据备份 (JSON)」**，即可下载专属备份文件；
* 更换电脑或手机时，点击「导入并恢复备份」，1 秒即可完整还原所有选题文案、生词库与备考进度。

## 🚀 发布与推送到 GitHub 规范流程

在您本机的终端或 Git 环境中，执行以下指令将此 V1 第一版代码发布至您的 GitHub 账号：

```bash
# 1. 在 GitHub 上新建一个仓库（例如命名为 kansodesk 或 personal-workbench）
# 2. 在当前项目根目录下关联您的 GitHub 仓库地址：
git remote add origin https://github.com/您的用户名/您的仓库名.git

# 3. 切换为主分支并提交所有最新改动
git branch -M main

# 4. 创建 V1.0.0 第一版专属版本发布标签 (Git Tag)
git tag -a v1.0.0 -m "Release v1.0.0: 自媒体多账号流水线 + AI前沿科技矩阵雷达 + 1000词长篇情境语料备考工作台"

# 5. 推送代码及版本标签到 GitHub
git push -u origin main --tags
```
